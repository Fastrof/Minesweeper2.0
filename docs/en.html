Features

Everything reproduced is the original rule

The classic feel is matched item by item — everything new is built on top of it.

🖱️

Classic feel, 100%

Left click to reveal · right click cycles flag → question → blank · double click / middle click / both buttons to chord · the first click is always safe · the timer starts on the first reveal · all mines shown on a loss.

🗺️

36 levels in 6 chapters

Every level is a fixed board, starred by completion time (★★★ / ★★ / ★) and unlocked in order. Clearing one shows a settlement card, and in-game "◀ Previous / Next ▶" keeps you going.

🔧

Three items

Magnifier (reveals a 2×2 area; the clicked cell is the top-left corner) · sonar scan (reports only how many mines are inside 3×3) · time freeze (pauses the countdown for 20 seconds); the "🛒 Shop" in the board's top-right corner trades accumulated coins for items.

🛒

Coin shop (v1.4; cross-game since v1.5.1)

Each mine you sweep out earns 1 coin; open the "🛒 Shop" in the board's top-right corner any time — magnifier 30, sonar scan 20, time freeze 20. Coins accumulate across games (new games and levels no longer reset them), and bought items go straight into your inventory and are kept across games.

🧠

No-guess mode (v1.5)

When enabled, normal games only deal boards that can be solved by pure logic from the first click — there is always a certain next move, so you never have to guess. Off by default; very large or extremely dense boards fall back to a normal board. Normal games also have a "💡 Hint" button that highlights a cell proven safe (hinted games do not count for best times).

🎨

19-key adjustable themes

The palette is made of 19 color keys, with Classic, Dark, High-contrast and Paper built in — and you can override any single color.

🌏

Bilingual interface

The interface and every message support Simplified Chinese and English, switched at runtime (including Windows notifications and both About windows). A first install defaults to Simplified Chinese; switching needs no restart.

🌗

UI color theme

Follow system / light / dark, applied instantly and remembered. In dark mode the board is automatically kept visually separate from the window background (the board fill is nudged by a luminance rule; the high-contrast theme follows the same rule).

🏆

31 achievements

Worth 1000 points across lifetime, speed, levels, items and challenge categories; open "🏆 Achievements" at the bottom to track progress.

🔄

Updates on your terms

Schedule automatic checks (every launch / daily / weekly...), or pause them until a chosen date. The first launch after an upgrade shows What's new; you can revisit it from Settings.

🔊

Code-synthesized sound

Six sound effects — reveal, flag, chord, explosion, victory, startup — are synthesized as WAV in code at runtime. The repository contains no audio files at all.

♿

Screen-reader support

The self-drawn board exposes full UI Automation support, so a screen reader can read out "row 3, column 5, revealed, number 2" cell by cell.

Level mode

36 levels, unlocked one after another

A level is a fixed board plus a goal. Each level hard-codes a random seed and is created as a locked board, so the same level is always the same board — which is what makes retries, star farming and sharing meaningful.

Items

Three items, each with one job

You start with two of each; after that, each mine you sweep out earns 1 coin, spendable in the "🛒 Shop" in the board's top-right corner (magnifier 30 / sonar 20 / freeze 20). Coins accumulate across games, and bought items are kept across games too.

🔍

Magnifier

Reveals the 2×2 area whose top-left corner is the target cell, marking exactly where the mines are (clipped at the board edge).

  • Does not reveal or flag cells, so it never affects win/loss
  • Information is kept permanently by default (configurable to fade)
📡

Sonar scan

Tells you only how many mines are inside the chosen 3×3 area — never where they are.

  • Purely "how to read information"; it changes no board state
  • The same area can be scanned again (it just wastes an item)
🧊

Time freeze

Pauses the countdown for 20 seconds — one save for "I thought too long".

  • Affects only your time, never the board
  • Star ratings and best times pause along with it

Rendering & performance

1,000,000 cells on screen at ~70 FPS

The board is pure vector drawing. The bottleneck turned out to be draw call count, not pixels, so at far zoom the renderer merges same-colored runs into single rectangles and then merges structurally identical rows into vertical bands — a million calls collapse into a few dozen.

  • 14.4 msper frame, 1M cells
  • ≈ 70 FPSmeasured at full zoom-out
  • 23×faster than before
  • 4096×4096largest board per game
Every image above was rendered off-screen by the app itself on a real GPU and exported as a reference image — not a mockup.

Under the hood

No assets, fully testable, cleanly layered

Themes are pure palette-based vector drawing, sound effects are synthesized in code, and the icon is a hand-assembled multi-resolution ICO. That is not just tidiness — it answers the copyright red line: this project contains no assets taken from Windows 7 Minesweeper.

🧱

Two layers, one rule

MineSweeper.Core is a plain .NET library with zero UI dependencies holding every game rule; MineSweeper.App only displays and takes input.

The iron rule: "can this logic be tested without starting a UI?" If yes, it belongs in Core.

✅

389 unit tests

A gatekeeper for the level table, mine placement boundaries, a 1000×1000 empty board without stack overflow, atomic saves and corruption recovery, distinct waveforms — all runnable without a UI in about one second.

💾

Atomic saves

Settings, progress, records, level progress and history are separate files. Corruption is backed up and rebuilt; a newer schema version is refused and never overwritten. Delete the data folder to reset everything.

FAQ

Things you might be wondering

Why can't I use the keyboard on the board?

That is intentional — the project owner required pure mouse control, so the board is not focusable and has no focus ring. Text fields in the settings panel (seed, share code) still accept keyboard input. Arrow keys, Enter and Space do nothing on the board; that is not a malfunction.

Where is my save data?

For the unpackaged build: %LOCALAPPDATA%\MineSweeper2\. For the Store build: the app's local data folder. It holds settings.json, progress.json (progress and items), levelprogress.json, records.json (best times), history.json (lifetime stats), config.json (hand-editable configuration) and app.log. Deleting that folder resets everything.

Install says "unknown publisher" or the certificate is untrusted — what now?

The GitHub Release build uses a self-signed certificate, so the bundled .cer must be installed into the Trusted People store first (see the command above). The Microsoft Store version is signed by the Store and shows no such prompt.

Does it collect any of my data?

No. The only network access is the update check: it reads the GitHub public API (version number only, no personal data sent) and can be disabled in Settings; the Microsoft Store build never checks (the Store handles updates). There is no account, no telemetry and no ads; all saves stay on your machine and are deleted when you uninstall. See the privacy policy.

Can I change the difficulty and the numbers?

Yes. The settings panel lets you set board width, height and mine count (up to 4096×4096); item hold limits, magnifier width/height, shop prices and freeze duration live in config.json with no rebuild needed. All level numbers are in one table: Core/Levels/LevelTable.cs.
